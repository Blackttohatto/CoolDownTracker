# CoolDownTracker

Raid cooldown tracker for Turtle WoW (vanilla 1.12.1 + SuperWoW).

Tracks: Challenging Shout, Challenging Roar, Lay on Hands, Blessing of Protection,
Spirit Link, Innervate, Reincarnation, Soulstone, Rebirth.

## Installation
Drop the `CoolDownTracker` folder into `Interface/AddOns/`.

## Usage
- `/cdt` — toggle show/hide
- `/cdt clear` — clear all entries  
- `/cdt reset` — move frame to center
- `/cdt cfg` — open config
- `/cdt test` — add test entries
